# Zzen Automation

**Native C++ automation tools for Windows.**

We build desktop companions that automate repetitive gameplay tasks through screen recognition and standard keyboard and mouse input.

## Projects

| Project | Focus | Download |
| --- | --- | --- |
| [Zzen](https://github.com/zzen-automation/Zzen) | Chronicle match automation for **Inazuma Eleven: Victory Road**, with match selection, session controls, and diagnostics. | [Latest release](https://github.com/zzen-automation/Zzen/releases/latest) |
| [R-Zzen](https://github.com/zzen-automation/R-Zzen) | Visual automation for **Roblox Army Commander Tycoon**, including construction purchases, prestige, and keep-active controls. | [Latest release](https://github.com/zzen-automation/R-Zzen/releases/latest) |

## Getting started

Download the latest release from the project you need, extract the full archive, and follow its README. Both tools target **Windows x64** and currently require the **game interface to be set to Spanish**.

## Feedback & contributions

Report bugs and suggest improvements in the relevant repository:

- [Zzen issues](https://github.com/zzen-automation/Zzen/issues)
- [R-Zzen issues](https://github.com/zzen-automation/R-Zzen/issues)

Include the app version, steps to reproduce, and relevant diagnostic logs. Each repository contains its build instructions, validation notes, and license.
